# Backbencher's Got Talent — final videos

This package is locked to the six original images in [`../set`](../set). The curtains, ring emblem, stage, microphone, audience layout, and five-seat judges' panel remain unchanged.

There are **no cameramen, camera equipment, alternate rooms, or redesigned sets** in the finished material.

The exact show name, **BACKBENCHER'S GOT TALENT**, is fixed to the physical front face of the judges' panel wherever that face is visible.

## Finished videos

- `backbenchers_intro.mp4` — 9.6-second opening ident using `res/BACKBENCHERS! (1).mp3`.
- `backbenchers_trailer.mp4` — 36-second trailer using `res/BACKBENCHERS!.mp3`.

Both masters are H.264/AAC MP4, 1920 × 1080, 25 fps, progressive, BT.709, with 48 kHz stereo audio.

## Individual shots

The `clips/` directory contains 12 clean, editor-ready video shots from the original set angles. It contains no still-image experiments or cameraman variations.
